## Envelope

| Campo | Tipo | Significado |
| --- | --- | --- |
| `id` | inteiro | ID da entrega usado para identificar reenvios |
| `event` | string | Nome do evento |
| `createdAt` | string | Data e hora ISO 8601 do registro da entrega |
| `data` | objeto | Dados da operação financeira, incluindo o identificador em `data.id` |
| `test` | booleano | `true` nas entregas de teste |

Nos eventos de cobrança, `data.id` é o inteiro de seis dígitos retornado na criação. Nos eventos de saque, `data.id` é a string de seis dígitos retornada na solicitação do saque. Use esse campo para buscar a operação e o `id` do envelope para reconhecer o reenvio de uma entrega.

## Eventos emitidos

| Evento | Quando é enviado |
| --- | --- |
| `charge.paid` | Pagamento confirmado e valor líquido creditado |
| `charge.failed` | Cobrança recusada ou encerrada antes do crédito |
| `refund.completed` | Estorno confirmado de uma cobrança previamente paga |
| `payout.completed` | Saque confirmado pela adquirente |
| `payout.failed` | Saque recusado ou devolvido |
| `webhook.test` | Teste solicitado no painel |
